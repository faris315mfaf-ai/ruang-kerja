Ukuran & penempatan

Ukuran mengikuti konteks; ikon selalu berpasangan dengan teks atau punya label aksesibilitas.

Skala ukuran

16 dpchip, badge, tombol sm, kbd
18 dpikon dalam tombol (di kiri teks, jarak 8)
20 dpUI umum: ikon baris, ikon form
22 dptombol ikon app bar (di dalam 48), tab
24 dptab bar, tombol utama
26 dpikon tombol tengah tab bar
28 dpFAB, ikon hero, check-in
32 dpempty state (di ubin 64)

Penempatan baku

Tombol ikon app bar: bulatan 48, ikon 22, border 1, accessibilityLabel wajib ("Cari").
Ubin ikon baris: 44, radius 14, warna lembut (teal/info/warn/bad/ok/netral), ikon 22.
Ubin empty state: 64, radius 20, --grad-soft, ikon 28–32 warna link.
Ubin identitas (workspace): gradien palet + huruf kode atau ikon.
Tombol tengah tab bar: 54 bulat, ikon 26–28, stroke 2,2.

Aturan

• Stroke 1,9 (UI) / 2 (navigasi) / 2,2 (tombol tengah); tidak pernah diisi (outline saja), kecuali titik status.

• Warna ikon = warna teks di sebelahnya, atau --text-muted (netral), --link (aktif/teal), semantik untuk status. Tidak pernah hex.

• Ikon dekoratif accessibilityElementsHidden; ikon penyampai makna punya label teks.

• Bentrok: kit demo memakai layout-grid untuk "Lainnya", padahal layout-grid = tombol tengah Workspace. Android memakai menu untuk Lainnya (sama dengan web).

• Absen: web memakai map-pin, Android fingerprint (keputusan 9 Okt); keduanya diterima, Android memakai fingerprint.

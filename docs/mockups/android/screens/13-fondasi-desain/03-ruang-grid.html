Ukuran layar & zona jempol

Ponsel dirancang untuk satu tangan: aksi yang sering ada di sepertiga bawah, bacaan di atas.

Kelas layar & breakpoint

Ponsel · 360–430 dp
1 kolom, tab bar kapsul, bilah aksi melekat.
Lipat tertutup · 320–380 dp
Layar luar sempit: hanya beranda, check-in, notifikasi, gabung rapat.
Lipat terbuka · 840–900 dp
2 panel daftar–detail; Rail 96 dp di kiri menggantikan tab bar.
Tablet · ≥ 768 dp
Sama dengan lipat terbuka; kartu boleh 3 kolom. Kit: --w:834px;--h:1112px.

Android memilih shell dari lebar dp (useWindowDimensions), bukan model perangkat: < 768 = tab bar; ≥ 768 = Rail 96 (tanpa tab bar). Konten satu kolom maks. 600 dp.
